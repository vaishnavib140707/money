# Midnight Money

### Personal Budget & Expense Tracker

Midnight Money is a responsive personal finance web application designed to help users manage their monthly income, track expenses, plan daily spending, and build savings habits.

The application features user authentication and cloud-based data storage, allowing users to securely access their financial records across sessions and devices.

## Features

- **User Authentication:** Sign up, log in, and log out with Supabase Authentication.
- **Monthly Budget Planning:** Set monthly income and manage fixed bills.
- **Daily Spending Allowance:** Automatically calculate the available daily budget based on remaining funds and days in the month.
- **Expense Tracking:** Record expenses and view transactions by date.
- **Automatic Savings:** Allocate underspent amounts toward savings.
- **Budget Recalculation:** Adjust future daily allowances when spending exceeds the planned amount.
- **Savings Goals:** Create and track personal savings targets.
- **Cloud Data Storage:** Save and retrieve user-specific financial data using Supabase.
- **Responsive Design:** Use the application on desktop and mobile screens.

## Technologies Used

- **HTML5** — Web page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Budget calculations and application logic
- **Supabase Authentication** — User signup, login, and session management
- **Supabase Database (PostgreSQL)** — Cloud storage for budgets and savings goals
- **Git & GitHub** — Version control and project hosting

## How It Works

1. Create an account or log in.
2. Enter monthly income and fixed expenses.
3. View the automatically calculated daily spending allowance.
4. Record daily expenses and monitor the remaining budget.
5. Track savings and create savings goals.
6. Access saved financial data after logging in again.
